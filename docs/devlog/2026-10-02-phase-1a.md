## Decisions and open issues
- **scoring_model = `claude-sonnet-5-5` at $2 / $10 per MTok** (prices checked 2026-10-02).
  The plan's cost estimate (~60k input and ~18k output tokens per hour) gives about $0.30
  per hour, inside criterion 12. Opus 5.5 ($4 / $20) gives about $0.60 per hour and would
  fail criterion 12. This is a one-line change in config.toml.
- **Flag for phase 4:** the plan says to score "at temperature 0", but current models
  reject non-default sampling parameters (Sonnet 5.5 returns 400 for a non-default
  temperature). Phase 4 must get repeatability from the cache plus a fixed prompt and
  structured output, and the plan or ADR 0003 should be updated to match.
- `whisper_engine = "faster-whisper"`, `whisper_model = "small.en"`: placeholders until
  phase 2 measures both engines (ADR 0002).
- Weights (0.30 / 0.25 / 0.20 / 0.10 / 0.10 / 0.05) are untuned starting values for phase 9.
