# 2026-10-02 · Phase 1b: Contracts, cache, test fixture

## Built
- `clipper/models.py`: every contract in the plan, as frozen pydantic models with
  `extra="forbid"` (same style as `config.py`): `Word`, `Sentence`, `Candidate` (+ `Features`),
  `Score`, `ClipPlan`, `CropTrack`, `ClipResult`, `LabelSet` (+ `Moment`).
  - Times are `Seconds` (≥ 0, no NaN/inf). Spans (`Candidate`, `ClipPlan`, `Moment`) need
    `end > start`; `Word`/`Sentence` allow `end == start`.
  - `Score`: four ints 0–5, non-empty reason, `Title` = stripped, 1–40 chars, no newlines or
    control characters (Unicode category C). `ClipPlan.title` uses the same type.
  - `CropTrack.center_x` is a fraction of the source width (0–1), one entry per frame, same
    length as `face_found`.
  - `LabelSet.video_sha256` must be 64 lowercase hex chars; `heldout` is required; ≥ 1 moment.
  - File wrappers, one per stage file: `Transcript` (indices in range, word starts never go
    backwards, sentences ordered and not overlapping), `CandidateSet` (unique ids; used for
    `candidates.json` with `features=None` and for `signals.json` with features filled),
    `ScoreSet` (unique candidate ids), `Selection` (ranks exactly 1..K, unique candidates).
    The `meta.json` model is left to phase 2, which knows what ffprobe returns.
  - `write_model` / `read_model`; writes are atomic (temp file + `os.replace`).
- `clipper/cache.py`: `STAGES` in plan order; `sha256_file` (1 MiB chunks); `work_dir(video)` =
  `work/<first 16 hex of SHA-256>`; `stage_key(stage, inputs, settings)` = SHA-256 of
  `CACHE_VERSION`, the stage, each input's **content** hash (ordered, paths ignored) and
  canonical JSON settings (sorted keys, pydantic models dumped, NaN and non-JSON types raise);
  `is_done` (marker matches and every listed output exists), `mark_done` (atomic),
  `invalidate_from(stage)` for `--force` (that stage and all later ones). Unknown stage names
  raise `ValueError`.
- `tests/fixtures/make_fixtures.py` (macOS): 8 topics (sourdough, vintage watches, card points,
  marathon, houseplants, coffee, bike flats, Venus) spoken by `say -v Samantha -r 175`, 0.8 s
  gaps, padded to exactly 150 s. Each topic has its own background color, and a white square
  slides across the frame. libx264 CRF 30 + AAC 48 kb/s mono, bitexact flags, no metadata.
  `ffmpeg_bin` comes from `config.toml`. It writes `talk.mp4` and `talk.txt` (one paragraph per topic,
  exactly what `say` spoke).

## Numbers
- Fixture: `talk.mp4` 1,127,478 bytes (1.13 MB), 150.000 s, 4500 frames at 30/1 fps, 480x270 h264
  yuv420p, aac 22.05 kHz mono. 443 words. Speech per topic 15.2–17.8 s; speech + gaps
  140.5 s, then 9.5 s of silence at the end. `silencedetect` (−40 dB, 0.6 s) finds the 7 gaps
  at 17.3, 35.4, 53.1, 70.7, 87.8, 106.4 and 124.5 s.
- Deterministic: two regenerations gave the same SHA-256 (a7602ac3…79b5).
- `uv run pytest -q`: 138 passed in 0.29 s (models 84, cache 24, fixtures 3, CLI 14, config 13).
- ruff: all checks passed. `mypy clipper tests`: no issues in 13 files.

## What broke
- First fixture had only 104 s of speech for 6 topics (`say` at "175 wpm" ran at about
  190 wpm), which left 46 s of silence. Added two topics → 140.5 s.
- `drawbox` with `x='mod(t*60,…)'` drew the square at a fixed x=60 in every frame: drawbox
  doesn't re-evaluate x per frame here. Switched to `overlay` of a 40x40 `color` source,
  which does. Checked frames 150 and 1200: x = 300 and 200, as expected. Frame 4400 is at the
  wrap point (x ≈ 439 from float rounding).
